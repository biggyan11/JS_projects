# 🌤️ Weatherly — Live Weather App

A modern and responsive weather application built with **HTML, CSS, and JavaScript**.  
It uses the **OpenWeatherMap API** to provide real-time weather information and forecasts.

## 🚀 Live Demo

👉 [**View Live Demo**](https://YOUR-NETLIFY-URL.netlify.app/)

## ✨ Features

- 🌍 Search weather by city
- 📍 Get weather using your current location
- 🌡️ Current temperature and weather conditions
- 📅 5-day weather forecast
- 🌙 Dynamic weather-based backgrounds
- 🌡️ Celsius / Fahrenheit conversion
- 💾 Recently searched cities
- 📱 Responsive design for desktop and mobile
- ⚡ Real-time data using OpenWeatherMap API

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- OpenWeatherMap API
- LocalStorage
- Geolocation API
